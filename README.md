# Dark Mode Safari support / destek

Public support and privacy documents for Dark Mode Safari, an independent macOS Safari extension. All features are free; Apple handles optional consumable support tips.

- [Support / Destek](index.html)
- [Privacy / Gizlilik](PRIVACY.md)
- [Email support / E-posta desteği](mailto:info@iyonya.app)
- [Public issues / Herkese açık istekler](https://github.com/bahadiryl/dark-mode-safari-support/issues)

Support requests are public. Do not post private browsing history, passwords, purchase receipts or other sensitive information. GitHub account registration is needed only to post an issue, never to use email support or the app.

Destek istekleri herkese açıktır. Özel dolaşma geçmişi, parola, satın alma makbuzu veya hassas bilgi paylaşmayın. GitHub hesabı yalnızca istek yazmak için gerekir; e-posta desteği veya uygulama için gerekmez.

This repository contains support and privacy documents only, not application source.
